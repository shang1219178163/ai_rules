# 繁体转简体

整篇用 OpenCC `t2s` 一次转完。不要把正文拆给多个 agent，也不要用模型逐段改写。词典转换才不会把专名和用词改乱。

只改用户点名的文件。先写到临时文件，核对通过后再替换原文件。保留原换行，不要用编辑器整文件覆盖。

## 转换

依赖 `opencc-python-reimplemented`（`import opencc`）。未安装时：

```bash
python3 -m pip install -q opencc-python-reimplemented
```

用 `newline=""` 读入，`OpenCC("t2s").convert(text)` 转写。OpenCC 按词处理一对多，不要再按字表重转这些字：`於` `覆` `乾` `徵` `瞭` `藉` `儘`。

`著` 不在 OpenCC 字表里。先保护读 zhù 的词，再把其余 `著` 改成 `着`：

```python
protect = [
    "著作者", "著作权",
    "显著", "卓著", "昭著", "土著", "著称",
    r"(?<=的)著名", r"(?<=非)著名", r"(?<=最)著名", r"(?<=那)著名",
    r"(?<=些)著名", r"(?<=处)著名", r"(?<=种)著名", r"(?<=场)著名",
    r"(?<=个)著名",
    r"著名(?=的)", r"著名(?=强)", r"著名(?=区)", r"著名(?=遗)", r"著名(?=地)",
]
```

用占位符保护后再 `replace("著", "着")`，然后还原。这样「比划著名手势」「看著名单」「标注着名称」会变成「着」，「著名地标」「非著名」「著称」「土著」仍是「著」。

## 转完后必改

这些是大陆规范，OpenCC 不会自动改对：

| 原文 | 改成 | 不要改 |
|------|------|--------|
| `彰显著` | `彰显着` | |
| `凭藉` | `凭借` | `狼藉` `慰藉` |
| `藉机` | `借机` | |
| `牴触` | `抵触` | |
| 表示恢复的 `回复` | `恢复` | 表示答复、评论的 `回复` |

`回复` → `恢复` 只在对象是状态或资源时改，例如：`回复了年轻`、`回复如常`、`回复源能`、`回复伤势`、`回复晶核`、`回复速度`、`寿命是否能回复`、`能回复他七成`、战斗后的 `休息回复`。留言、帖子、`回复道`、`回复总部` 保持 `回复`。先打出含这些词的上下文，确认后再替换。

下列保持原样：`乾坤`、`瞭望`、`神祇`、`覆盖`、`颠覆`、`覆没`、`翻来覆去`。`典藉` 不是繁简问题，不要改成 `典籍` 或 `典借`。

## 核对

替换原文件前确认：

- 行数、换行风格与原文一致，开头标题还在。
- `TSCharacters.txt` 里「字本身不是自身映射」的字只应剩下 `覆` `藉` `祇` `瞭` `乾`。`牴` 应为 0。
- 剩下的 `著` 都能对上保护词：`显著` `卓著` `昭著` `土著` `著称` `著名` `著作者` `著作权`。
- 抽查开头：`随着` `喘着` `接着` `体内` `经历`，以及一处 `显著` 或 `著名`。

核对通过后 `os.replace` 临时文件覆盖原路径。不要留 `.converting` 文件。
